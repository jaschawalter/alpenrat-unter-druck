# Alpenrat unter Druck

Ein Einzelspiel für Geografie in Klasse 6. Das fiktive Alpendorf Tannenbrunn entwickelt sich von 1950 bis 2002. Die drei Balken zeigen vereinfachte Spielwerte.

## GitHub Pages

1. ZIP entpacken und die entpackten Dateien und den Ordner `assets` gemeinsam ins Stammverzeichnis eines GitHub-Repositorys hochladen. Dort muss `index.html` liegen.
2. Im Repository unter **Settings → Pages** den gewünschten Branch und **/ (root)** als Quelle wählen.
3. Den veröffentlichten Pages-Link im Browser öffnen.

Zum Ausprobieren kannst du nach dem Entpacken die Datei `index.html` direkt im Browser öffnen. Die Webseite ist statisch. Eine laufende Partie wird im verwendeten Browser gespeichert.

## Materialgrundlage

- Ernst Klett Verlag, Arbeitsblatt „Tourismus in den Alpen“ mit Dorfzeichnungen für 1950 und 2002.
- *Heimat und Welt 5/6* (2022), S. 128–129, Massentourismus, sanfter Tourismus und Alpenkonvention.
